## Main projects

**[job-board](https://github.com/Md-Foisal/job-board)**: a hiring platform for candidates, employers and staff. [Live as HearBack](https://hearbackjobs.com)
Laravel 13, PHP 8.4, Livewire, Filament, Fortify, Pest.

**[Tandoor House](https://github.com/Md-Foisal/tandoor-house)**: one platform for a made-up restaurant. [Demo](https://tandoor-house.onrender.com) and [film](https://youtu.be/NwxVs3GprHQ)
Laravel 13, React 19, Inertia, TypeScript, Tailwind CSS, Reverb, Stripe in test mode.

- Ordering for delivery, pickup and dine-in, with a QR code on each table.
- Table booking with deposits.
